# Travelista - Local Tourist Day-Visit Planner

A web-based application designed to help tourists discover and plan one-day visits to attractions within a 25 km radius of Akkaraipattu, Sri Lanka.

## 🚀 Features
- **Tourist Portal:** Browse places, filter by category, view details on an interactive map (Leaflet), and create a one-day itinerary.
- **Admin Dashboard:** Secure panel to Add, Edit, and Delete places, including image uploads.
- **Reviews:** Registered users can leave ratings and comments.
- **Trilingual Support:** UI scaffolded for English, Tamil, and Sinhala.

## 🛠️ Technology Stack
- **Frontend:** React.js, Vite, CSS3, Leaflet
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas (Mongoose)
- **Version Control:** Git & GitHub

## 💻 How to Run Locally
1. Clone the repository: `git clone https://github.com/Zahara2003/Travelista-Project.git`
2. Navigate to backend: `cd backend` -> `npm install` -> `npm start`
3. Navigate to frontend: `cd frontend` -> `npm install` -> `npm run dev`
